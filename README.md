# FillUp Gas Finder

A responsive gas station finder prototype with account/profile screens, vehicle details, station search, fuel and amenity filters, radius selection, favorites, reviews, trip destination search, and fill-up spending logs.

## Run it

Open `index.html` in a browser, or enable GitHub Pages for this repository from **Settings → Pages** and choose the `main` branch with the `/ (root)` folder.

## Prototype notes

Station names, ratings, and prices are sample data. Account information, preferences, saved stations, reviews, and spending history are stored in the current browser using local storage. Real account authentication, cloud sync, live prices, and map/geocoding services are not connected.
